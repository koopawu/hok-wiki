# 荣耀图鉴 · HOK WIKI

玩家自建的非官方《王者荣耀》资料站，暗色电竞风（哑光金 + 墨蓝）。主要面向 PC、兼容手机，目标是：查英雄、看出装、学点位、按时间轴做对决策，再用训练与复盘把段位打上去。

## 内容板块

- **上分指南（S45 · 月照长安，核对 2026-10-26）**：上分路线、按分路与水平的版本推荐、BP 选将与阵容分析（九项职责）、五路专修、实战专项（射手防抓 / 英雄池 / 团战站位）、八棵局势决策树 + 六个关键帧案例、组排沟通、分段训练路线。
- **英雄资料库**：133 个英雄 / 形态，十秒速查（定位、核心连招、默认出装铭文、克制对象、前中后任务、本局判断），技能数据（简明 / 完整双模式，共 541 个技能），进阶思路；10 位主练英雄附对位与局势攻略（好打 / 难打 / 均势、核心装 + 灵活位、强势期、逆风任务）。
- **装备合成图谱**：115 件装备按低阶 / 中阶 / 高阶分列，走线直接展示合成关系，右侧查看属性、效果与适用局势。
- **铭文系统**：五级铭文图鉴与搭配思路。
- **峡谷地图**：22 个点位（红蓝 BUFF、六类普通野怪、边路资源、龙坑、草丛 / 视野 / 防御塔 / 高地），总图热点 + 点位目录联动，附实局画面。
- **对局时间轴**：0—4 / 4—10 / 10 分钟以后各位置该做什么。
- **娱乐玩法**：王者农场、王者麻将、S45 共鸣之战。
- **复盘工具**：真实写入数据库的赛后复盘（分路 / 英雄 / 目标 / 失误原因 / 替代动作），自动统计常见失误、最近 3 局 vs 之前 3 局趋势与下一周唯一训练建议。

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui ｜ Hono + tRPC 11 + Drizzle ORM + MySQL（复盘持久化）｜ Docker 多阶段构建（运行时 `node dist/boot.js`）。

## 本地运行

```bash
npm ci
npm run dev          # http://localhost:3000，HMR
npm run check        # 类型检查
npm run build        # 前端产物 dist/public + 后端单文件 dist/boot.js
npm start            # 生产模式
npm run db:push      # 同步数据库 schema（复盘功能需要）
```

环境变量参考 `.env.example`；真实 `.env` 不入库。

## 目录结构

- `src/pages` / `src/sections`：页面与版块
- `src/data`：英雄、装备、铭文、地图点位、上分内容等数据
- `src/components` / `src/components/climb`：通用组件与上分指南模块
- `src/assets/images`：素材（版权归原作者及腾讯所有，见下方声明）
- `api` / `contracts` / `db`：tRPC 路由、类型契约、Drizzle schema
